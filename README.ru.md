# MISOUND

Языки: [简体中文](README.md) · [English](README.en.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Русский](README.ru.md) · [Español](README.es.md)

MISOUND — это сайт анонимных текстовых чатов с комнатами в реальном времени, восемью местами, правами владельца комнаты, синхронизацией онлайн-радио и отдельной громкостью для каждого слушателя. Версия использует только стандартную библиотеку Node.js для HTTP, HTTPS, статических файлов и WebSocket. База данных и сторонние зависимости не требуются.

## Сайт

- Основной домен: <https://0372api.top>
- Дополнительный домен: <https://zwj.76jh.com>
- Чат: <https://0372api.top/prototype/>

## Возможности

- Без регистрации и входа; временный ник генерируется при входе.
- Список комнат в реальном времени, создание, вход и выход.
- Сообщения синхронизируются; последние 80 хранятся только в памяти.
- Восемь синхронизированных мест: вход, выход, мьют, запрет текста, kicking, передача владельца и закрытие.
- Первый вошедший в пустую комнату становится владельцем; создатель комнаты тоже становится владельцем.
- Владелец управляет радио: воспроизведение, пауза, предыдущий/следующий канал и выбор источника.
- У каждого участника есть локальный регулятор громкости.
- Правки администратора и скрытый вход видны только настроенному IP и проверяются сервером.
- HTTP перенаправляет на HTTPS, WebSocket использует `wss://`.
- Несколько HTTPS-доменов поддерживаются через SNI.

## Быстрый запуск

```bash
cd site-home
node server.js
```

По умолчанию HTTP слушает `0.0.0.0:80`, HTTPS — `0.0.0.0:443`. Переменные `HOST`, `PORT` и `HTTPS_PORT` изменяют адреса и порты. Для 80/443 в Linux нужны root или `CAP_NET_BIND_SERVICE`, в Windows — права администратора.

## Важное для развертывания

1. Настройте DNS A-запись на IP сервера.
2. Откройте TCP 80/443 в группе безопасности и брандмауэре.
3. Используйте Node.js 18 или новее.
4. Применяйте настоящий TLS-сертификат и не публикуйте `certs/` и приватные ключи.
5. Запускайте сервис через NSSM, pm2 или systemd.
6. Перезапускайте Node после обновления сертификатов.

## Текущие ограничения

- Голос пока работает только как локальный захват и предпросмотр волны; для группового голоса нужен WebRTC, ZEGO или аналог.
- Комнаты и сообщения хранятся только в памяти.
- Тексты о приватности являются черновиком и требуют юридической проверки.
