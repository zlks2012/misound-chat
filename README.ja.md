# MISOUND

言語: [简体中文](README.md) · [English](README.en.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Русский](README.ru.md) · [Español](README.es.md)

MISOUND は、リアルタイムルーム、8席の状態管理、ルームオーナー管理、オンラインラジオ同期、リスナーごとの音量調整に対応した匿名テキストチャットサイトです。Node.js 標準ライブラリのみで HTTP、HTTPS、静的ファイル配信、WebSocket を実装しており、データベースや外部ランタイム依存は不要です。

## サイト

- 主要ドメイン: <https://0372api.top>
- 予備ドメイン: <https://zwj.76jh.com>
- チャットルーム: <https://0372api.top/prototype/>

## 主な機能

- 登録不要、ログイン不要。入室時にランダムなニックネームを生成
- リアルタイムのルーム一覧、作成、入室、退室
- テキストはリアルタイム同期。最新80件のみサーバーメモリに保持
- 8席の状態同期、着席/離席、ミュート、発言禁止、退出、オーナー譲渡、ルーム終了
- 空きルームの最初の参加者がオーナーになり、作成者も既定でオーナー
- オーナーはラジオの再生、一時停止、前後チャンネル、音源選択を操作
- 各メンバーは自分のブラウザだけに適用される音量スライダーを利用
- 管理者権限と不可視入室は許可された IP にのみ表示され、サーバー側でも検証
- HTTP は HTTPS にリダイレクトし、WebSocket は `wss://` を使用
- SNI による複数 HTTPS ドメイン対応

## クイックスタート

```bash
cd site-home
node server.js
```

既定では HTTP が `0.0.0.0:80`、HTTPS が `0.0.0.0:443` で待機します。`HOST`、`PORT`、`HTTPS_PORT` で変更できます。80/443 を使うには Linux では root または `CAP_NET_BIND_SERVICE`、Windows では管理者権限が必要です。

## 運用の要点

1. DNS の A レコードをサーバー IP に設定します。
2. クラウドセキュリティグループとサーバーファイアウォールで TCP 80/443 を許可します。
3. Node.js 18 以上を使用します。
4. 正規 TLS 証明書を使用し、`certs/` と秘密鍵を Git に含めません。
5. NSSM、pm2、systemd などでプロセスを管理します。
6. 証明書更新後は Node プロセスを再起動します。

## 現在の境界

- 音声はローカルキャプチャと波形プレビューのみです。多人数音声には WebRTC、ZEGO などが必要です。
- ルームとメッセージはメモリのみで保持され、再起動で消えます。
- プライバシー文面は草案のため、正式公開前に法務確認を行ってください。
