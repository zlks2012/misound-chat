# MISOUND

언어: [简体中文](README.md) · [English](README.en.md) · [한국어](README.ko.md) · [日本語](README.ja.md) · [Русский](README.ru.md) · [Español](README.es.md)

MISOUND는 익명 텍스트 채팅 웹사이트입니다. 실시간 방, 8개 좌석 상태, 방장 관리, 온라인 라디오 동기화, 청취자별 음량 조절을 지원합니다. 이 버전은 Node.js 표준 라이브러리만으로 HTTP, HTTPS, 정적 파일 서비스, WebSocket을 구현하며 데이터베이스나 외부 런타임 의존성이 필요하지 않습니다.

## 사이트

- 기본 도메인: <https://0372api.top>
- 보조 도메인: <https://zwj.76jh.com>
- 채팅방: <https://0372api.top/prototype/>

## 주요 기능

- 회원가입과 로그인 없이 입장 시 임시 닉네임 생성
- 실시간 방 목록, 방 생성, 입장, 퇴장
- 실시간 텍스트 동기화, 최근 80개 메시지를 서버 메모리에만 보관
- 8개 좌석 상태 동기화 및 상/하麦, 음소거, 입력 금지, 강제 퇴장, 방장 이양, 방 종료
- 빈 방의 첫 입장자가 방장이 되고, 방 생성자도 기본 방장
- 방장이 라디오 재생, 일시정지, 이전/다음 채널, 음원 변경을 제어
- 모든 사용자는 자기 브라우저에서만 적용되는 음량 슬라이더 사용
- 관리자와 은신 입장은 설정된 허가 IP에만 표시되며 서버에서도 검증
- HTTP는 HTTPS로 자동 이동하고 WebSocket은 `wss://` 사용
- SNI로 여러 HTTPS 도메인 지원

## 빠른 시작

```bash
cd site-home
node server.js
```

기본값은 HTTP `0.0.0.0:80`, HTTPS `0.0.0.0:443`입니다. `HOST`, `PORT`, `HTTPS_PORT` 환경 변수로 변경할 수 있습니다. 80/443 포트를 바인딩하려면 Linux에서 root 또는 `CAP_NET_BIND_SERVICE`, Windows에서 관리자 권한이 필요합니다.

## 배포 요점

1. DNS A 레코드를 서버 IP로 설정합니다.
2. 클라우드 보안 그룹과 서버 방화벽에서 TCP 80/443을 허용합니다.
3. Node.js 18 이상을 사용합니다.
4. 공인 TLS 인증서를 사용하고 `certs/`와 개인 키는 Git에 커밋하지 않습니다.
5. NSSM, pm2, systemd 등으로 프로세스를 상시 관리합니다.
6. 인증서 갱신 후 Node 프로세스를 재시작합니다.

## 현재 한계

- 음성은 현재 로컬 캡처와 파형 미리보기만 제공됩니다. 다자 간 음성은 WebRTC, ZEGO 등이 필요합니다.
- 방과 메시지는 메모리에만 저장되어 프로세스가 재시작되면 초기화됩니다.
- 개인정보 문구는 제품 초안이므로 정식 출시 전 법률 검토가 필요합니다.
